# Formative 3 - Group 8

## Overview
This project implements probability distributions, Bayesian probability, and gradient descent algorithms.

## Contents

### Part I - Binomial Distribution
- Custom implementation of factorial and binomial coefficient functions
- Binomial probability mass function (PMF)
- Example: Calculating probability of students scoring 20/20
- Visualization of binomial distribution

### Part II - Bayesian Probability
- Medical diagnosis scenario using Bayes' theorem
- Step-by-step calculation of posterior probabilities
- Sequential updates with multiple test results
- Visualization of probability

### Part III - Gradient Descent
- Manual implementation of gradient descent algorithm
- Linear regression with two data points
- Parameter tracking (slope m and intercept b)
- Cost function (MSE) visualization over iterations

## Files
- `Untitled.ipynb` - Main notebook with all implementations
- `Gradient_descent_calculations.pdf` - Supporting calculations

## Requirements
- Python 3.x
- NumPy
- SciPy
- Matplotlib
